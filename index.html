          How it works, data sources and assumptions

          Substitution rules. Capacitance and case size must match. Voltage rating can only go up. Dielectric can only go up (Y5V, X5R, X7R, C0G). Tolerance can only get tighter. Grades aren’t a ladder: AEC-Q200 can replace commercial, but not medical. Changed or missing specifications need engineering review; end-of-life parts are ruled out.

          Comparison and planning. Each candidate is compared against the original. The approval path and production date are estimates based on typical review, validation, AML and PPAP durations. Actual requirements vary by company and customer.

          Data. MPN lookup uses Nexar with Mouser as fallback. Missing provider fields remain unknown. Description searches use a 30-part demo catalog with simulated stock, lead times and prices. Confirm specifications against the current manufacturer datasheet before approving any substitution.
